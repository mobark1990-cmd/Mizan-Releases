# Mizan Releases

ملفات إصدارات تطبيق **ميزان / رشيد** (أندرويد) فقط، بدون كود. التطبيق يقرأ `latest-rasheed.json` ويحدّث نفسه من الداخل.

- `latest-rasheed.json`: آخر إصدار (`versionCode`, `versionName`, `apkUrl`, `sha256`).
- ملفات الـAPK في صفحة [Releases](../../releases).
- الـAPK موقّع بمفتاح مبارك الموحد؛ التطبيق يرفض أي تحديث توقيعه مختلف أو بصمته لا تطابق.
